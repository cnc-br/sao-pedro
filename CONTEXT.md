# Contexto: São Pedro (Identidade & Pessoas)

O São Pedro é o guardião central de identidade e dados pessoais do ecossistema CNC-Gestão.

## Glossário Ubíquo

**Usuário**:
Credencial de acesso ao sistema (email, WhatsApp, papel e status ativo), opcionalmente vinculada a uma Pessoa.
_Evitar_: conta, login, acesso

**Pessoa**:
O fiel inscrito na base do Caminho Neocatecumenal, com dados civis e religiosos; pode ter um Usuário vinculado.
_Evitar_: membro, cadastro, cliente

**Papel**:
O nível de permissão de um Usuário (ex.: `ADMIN`, `SECRETARIA_CNC`, `NAO_IDENTIFICADO`).
_Evitar_: perfil, tipo de usuário
